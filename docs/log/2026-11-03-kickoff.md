## 結論摘要

- 進場方式：先備緊急預備金 → 開戶 → 市值型 ETF 定期定額 → 邊投邊學 → 寫好規則再加碼
  - 詳見 [01-getting-started](../knowledge/01-getting-started.md)
- 網路推薦方法：台股市值型 ETF、VT、Bogleheads 三基金、核心衛星、股債配置
  - 詳見 [02-recommended-methods](../knowledge/02-recommended-methods.md)
- 商品比較：新手優先 市值型 ETF、債券 ETF、零股、美股 ETF；避開融資、權證、期貨、選擇權
  - 詳見 [03-products-comparison](../knowledge/03-products-comparison.md)
- 四種入門方案 A／B／C／D
  - 詳見 [04-starter-plans](../knowledge/04-starter-plans.md)
- 系統規劃：知識庫 → Python 儀表板（先做回測器）→ AI 問答
  - 詳見 [05-system-design](../knowledge/05-system-design.md)
