選代號、填每月投入金額和期間，按「開始回測」。每月第一個交易日買進，一直不賣。

## 怎麼看結果

- **年化報酬**：平均每年賺多少（考慮每一筆投入的時間點），見[名詞解釋](../glossary/04-return-risk.md#年化報酬)
- **最大跌幅**：持有期間價格從高點跌下來的最大幅度
- **報酬率走勢**：虛線是 0%，掉到線下就是帳上虧損；圓點是帳上最慘的時候。運氣不好時會怎樣，見[這篇](../knowledge/10-bad-luck-scenarios.md)

## 限制

- 只能選事先整理好的代號；要查其他代號，用本機的回測器（`uv run streamlit run src/invest/app.py`）
- 沒有算手續費，假設可以買小數股
- 資料不是即時的：價格整理到上方日期欄位的最後一天，之後會定期更新

## 資料來源

- [FinMind 台股、美股歷史價格與股利資料](https://finmind.github.io/)
