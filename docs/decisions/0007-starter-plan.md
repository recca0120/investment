## 背景

使用者是股市新手。[入門方案](../knowledge/04-starter-plans.md)整理了四種起步方式，但一直沒選定。原本直接請使用者提供「金額、期間、風險承受度」，新手很難回答，所以改成問生活化的問題（自我檢查），再對照一般原則。

## 自我檢查的結果（只記判斷用的類別，不記金額）

| 項目 | 結果 | 代表什麼 |
|---|---|---|
| 緊急預備金 | 能撐 3～6 個月 | 達到一般建議範圍，可以開始投資 |
| 高利率負債 | 沒有 | 不用先還債 |
| 每月可投入 | 小額 | 適合定期定額；要選零股／定期定額手續費低的券商 |
| 錢多久不會用到 | 1～3 年，沒有確定用途，只想保留彈性 | 3 年內可能用的錢不適合全部放股票（短期可能大跌 30% 以上） |
| 大跌 30% 時 | 想加碼 | 心態好，但還沒實際經歷過，需要用小錢驗證 |
| 投入時間 | 想多學、也想試著選股 | 適合核心＋衛星 |
| 外幣／海外帳戶 | 還不確定 | 先用台股帳戶開始，以後要買 VT 再加開複委託 |

## 選項

| 方案 | 和使用者條件的關係 |
|---|---|
| A 極簡懶人 | 最省事，但使用者想多學，學到的較少 |
| B 全球股債 | 需要外幣帳戶，使用者還沒決定 |
| C 核心＋衛星 | 符合「想學選股」，但還沒經歷過下跌就開始選股，風險較高 |
| D 先練習 3 個月 | 用小錢驗證自己面對漲跌的真實反應，之後再決定 |

## 決定

1. **錢分成兩份**：彈性金（1～3 年內可能用到，放存款或定存）和長期金（5 年以上不動）。只有長期金拿去定期定額
2. **先走 D，3 個月後再決定是否轉 C**：前 3 個月每月小額定期定額一檔台股市值型 ETF（0050 或 006208），同時寫投資日記；3 個月後回頭看日記，決定要不要提高金額、要不要用一小部分練習選股

## 理由

- 預備金和負債的前提已經滿足，可以開始
- 「可能會用的錢」不放股票，避免需要用錢時剛好遇到大跌、只能認賠
- 「大跌想加碼」是想像，先用小錢實際經歷，比現在就決定大金額或選股準確
- 台股市值型 ETF 不需要外幣帳戶，外幣的事可以之後再決定，不用重來
