- 日期：2026-11-03
- 對應 issue：#3

## 背景

定期定額回測器（#5）需要台股（0050、006208）與美股（VT）的長期歷史價格，並且要正確處理股票分割與股利再投入。

## 選項

- 證交所：官方，但一次只能查一個月，也沒有還原價
- FinMind：整理官方資料，不帶 token 也能用；台股是原始價格，但有股利與分割事件可以自己調整
- yfinance：直接提供還原價，但屬於非官方資料，實測有一筆不存在的股利

## 決定

- 主要來源：FinMind
  - 台股：原始收盤價＋現金股利＋分割事件，自己計算還原價
  - 美股：`USStockPrice` 的 `Adj_Close`
- yfinance 只用於契約測試的交叉驗證
- 資料在本機快取，不進 git
- 先不註冊 token；呼叫次數不夠時再註冊（token 放在 `.env`，不 commit）

## 理由

- 台股數字和證交所官方完全一致，計算過程透明、可以驗證
- 歷史資料從上市日開始（0050 從 2003 年），比 yfinance 多 6 年
- 美股 `Adj_Close` 和 yfinance 只差 0.005%
- 詳細實測數據見 [股價資料來源評估](../knowledge/06-data-sources.md)
