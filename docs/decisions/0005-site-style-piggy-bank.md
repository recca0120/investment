## 背景

存摺帳本風格（0004）偏正式，使用者希望網站「輕鬆一點」。先導入 Tailwind（#17，外觀不變），再改風格（[#19](https://github.com/recca0120/investment/issues/19)）。

## 選項

- A 粉圓手帳：紙膠帶、圓章貼紙、jf 粉圓字體，首頁存摺貼在手帳上
- B 小豬撲滿：圓體字、天空藍底，首頁是撲滿，每月存入就掉一枚硬幣
- C 存摺加輕鬆版：保留存摺，只換圓體、加大圓角、配色變亮

## 決定

採用 B（使用者選擇）。

| 項目 | 日間 | 夜間 |
|---|---|---|
| 天空（底色） | `#EAF2FA` | `#121B26` |
| 雲（卡片） | `#F8FBFE` | `#1A2533` |
| 墨（標題） | `#1E2A3A` | `#E8EEF5` |
| 金幣（主要強調色） | `#F2B632` | `#F5C451` |
| 小豬（只用在撲滿） | `#F29CB4` | `#E98AA6` |
| 連結 | `#1F64A8` | `#A9D0F6` |
| 字體 | Chiron GoRound TC（圓體，400／700／900） | 同左 |

- **撲滿是全站唯一的大膽元素**，也是唯一有自動播放動畫的地方：每一筆年度紀錄是一枚硬幣，依序掉進投幣孔，句子裡的月數、累計存入、市值跟著換成那一年的真實數字
- 開啟「減少動態效果」或不執行 JS 時，直接顯示最終數字（HTML 裡就是最終狀態）
- 每年的存入紀錄收在「看每一年的存入紀錄」裡，首頁不那麼密
- 金幣色用在「存錢」相關的小地方：閱讀順序的編號（文章真的有先後順序）、引言的左線、含息再投的標記
- 其他地方保持安靜：只有首頁撲滿是卡片，其餘不做成卡片；圓角讓頁面柔和
- 內文、次要文字、連結對底色的對比都至少 4.5:1（WCAG AA），有自動化測試檢查

## 理由

- 定期定額就是「每個月丟一點錢進去」，撲滿比存摺更生活、更輕鬆
- 動畫不是裝飾：硬幣數量和金額變化都是真實回測資料，看動畫就看到十年的累積
- 圓體字讓整體語氣變輕鬆，但標題仍用 900 粗細，維持層次
